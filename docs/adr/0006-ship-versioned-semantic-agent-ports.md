# Ship versioned semantic agent ports

The first bundle contains `scout`, `delegate`, `researcher`, `worker`, `reviewer`, and `oracle` as deliberate adaptations of nicobailon `pi-subagents` v0.70.1, with attribution preserved. The ports use only `@gotgenes/pi-subagents` core capability tools, rely on its injected parent-coordination protocol, and are updated deliberately in companion releases rather than fetched or transformed during Agent Sync.
