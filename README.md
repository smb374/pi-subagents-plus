# Pi Subagents Plus

An extension to extend @gotgenes/pi-subagents for personal needs

## Install

```sh
pi install npm:@smb374/pi-subagents-plus
```

## Usage

Start Pi normally. This scaffold does not yet add tools, commands, or other behavior.

## Development

```sh
just setup
just install
just coverage
```

`src/index.ts` is the direct TypeScript entry; `npm run verify` checks source, tests, and the installed npm artifact.
